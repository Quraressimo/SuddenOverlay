각각의 메뉴는 다음과 같은 기능을 가집니다.

레인 커버 목록 : 하단에 값을 설정할 레인 커버를 선택합니다. 마우스로 선택할 수 있습니다.

커버 설정 :  커버와 관련된 설정을 할 수 있습니다.

레인 커버 추가  :  레인 커버를 추가합니다.

선택한 커버 삭제 : 추가한 커버를 삭제합니다. 메인 커버는 삭제할 수 없습니다.

모두 표시/모두 숨기기 : 레인 커버를 표시하거나 숨길 수 있습니다. 기본 단축키는 F6입니다.

X좌표, Y좌표 : 커버위 위치를 조절합니다. 듀얼 모니터 이상일 경우 -값이 들어갈 수 있습니다.

너비, 높이 : 커버의 크기를 조절합니다.

불투명도 : 커버의 불투명도를 조절합니다. 이미지 없이 단색일 때만 적용됩니다.

색상 HEX : 커버의 색상을 조절합니다.

이미지 : 찾아보기... 후 이미지를 선택할 수 있습니다. png, jpg, jpeg, bmp, webp 확장자를 지원합니다.

<img width="247" height="54" alt="image" src="https://github.com/user-attachments/assets/decec2a4-1e68-4e01-a069-c4bb959b679f" />

설정 적용 : 위에서 설정한 값을 적용합니다. 왠만하면 눌러주는게 좋습니다.

단색 : 이미지 경로를 지우고 단색으로 바꿉니다.

<br>

환경 설정

<img width="902" height="832" alt="image" src="https://github.com/user-attachments/assets/843f2e56-9dd2-4c0c-b2b0-ad1d5bd2233a" />

항상 위에 표시 : 설정 창과 레인 커버를 설정할 수 있습니다.

앱 다크 모드 : 아시는 그거입니다.

단축키 설정 : 레인 커버 표시/숨기기와 프로그램 종료 단축키를 설정할 수 있습니다. 가급적이면 F숫자키로 부탁합니다.

<br><br>

레인 커버를 추가, 이동한 흔적이 있다면 동일 경로에 SuddenOverlay_plus_settings.json 파일이 생성됩니다.

해당 파일이 있다면 프로그램 재실행시 종료 전 저장된 위치, 이미지를 가지고옵니다.

해상도나 용량이 너무 큰 파일은 추천하지 않습니다.<br>
해당 이슈로 강제 종료시 SuddenOverlay_plus_settings 파일을 삭제 후 재실행해주세요(초기값으로 설정)
